# Lori — Telegram AI-ассистент на Gemini

Асинхронный Telegram-бот с характером умного и дружелюбного ассистента.
Работает на Google Gemini API, запускается локально, помнит контекст диалога
и адаптирует тон под время суток.

## Возможности

- Контекстный диалог — бот помнит историю в рамках сессии
- Приветствие по времени суток (утро / день / вечер / ночь)
- Фильтр мата и запрещённых тем (настраивается в `bad_words.py`)
- Разбивка длинных ответов под лимит Telegram (4096 символов)
- Индикатор «печатает…», пока Gemini думает
- Обработка ошибок API: лимиты (429), блокировки безопасности, таймауты
- Настройка через `.env` — без правки кода
- Понятные сообщения об ошибках при запуске

## Стек

- Python 3.10+
- [aiogram 3](https://docs.aiogram.dev/) — асинхронный фреймворк для Telegram
- [Google Gemini API](https://ai.google.dev/) через SDK `google-genai`
- [python-dotenv](https://pypi.org/project/python-dotenv/) — чтение `.env`

## Быстрый старт

1. **Установите Python 3.10+** — [python.org/downloads](https://www.python.org/downloads/)

2. **Установите зависимости:**
pip install -r requirements.txt

3. **Получите токен бота** у [@BotFather](https://t.me/BotFather) в Telegram.

4. **Получите бесплатный ключ Gemini** на [aistudio.google.com/apikey](https://aistudio.google.com/apikey).

5. **Создайте `.env`** — скопируйте `.env.example` и переименуйте копию в `.env`, затем впишите ключи:
BOT_TOKEN=ваш_токен_от_BotFather
GEMINI_API_KEY=ваш_ключ_Gemini

6. **Запустите бота:**
python bot.py

7. Откройте своего бота в Telegram и отправьте `/start`.

## Настройка

Все настройки — в файле `.env`:

| Переменная | Что задаёт | По умолчанию |
|---|---|---|
| `BOT_TOKEN` | Токен Telegram-бота | — (обязательно) |
| `GEMINI_API_KEY` | Ключ Gemini API | — (обязательно) |
| `GEMINI_MODEL` | Модель Gemini | `gemini-3.5-flash-lite` |
| `TIMEZONE_OFFSET` | Смещение от UTC в часах | `3` (Москва) |
| `TIMEZONE_NAME` | Название часового пояса | `Москва` |

**Характер бота** меняется в `prompts.py` → переменная `SYSTEM_PROMPT`.
**Тексты ответов** — там же, в словаре `TEXTS`.
**Фильтр мата** — в `bad_words.py`.

## Команды бота

- `/start` — начать заново, сбросить историю
- `/clear` — очистить историю диалога
- `/help` — справка

## Ограничения

- Бот работает, пока запущен на вашем компьютере (для 24/7 нужен VPS)
- История диалога хранится в памяти и сбрасывается при перезапуске
- Понимает только текст (без картинок, голоса, файлов)
- Лимиты бесплатного Gemini API определяет Google
