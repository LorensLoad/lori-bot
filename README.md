# 🤖 Lori — персональный AI-ассистент в Telegram

![Version](https://img.shields.io/badge/version-1.1.0-blue)
![Python](https://img.shields.io/badge/python-3.10%2B-green)
![License](https://img.shields.io/badge/license-see%20LICENSE-lightgrey)

**Lori** — Telegram-бот на базе нейросети (через [Groq API](https://console.groq.com)) с характером «Джарвис + Пятница + Карен»: вежливый, дружелюбный, с лёгким юмором и всегда по делу. Бот помнит контекст диалога, знает текущее время и фильтрует нежелательный контент.

---

## ✨ Возможности

- 💬 **Умный диалог** — ответы на вопросы, помощь с кодом, объяснение сложного простыми словами
- 🧠 **Память** — история диалога и факты о пользователе хранятся в SQLite
- 🕐 **Знает время** — приветствие по времени суток, актуальная дата и время с учётом часового пояса
- 🛡 **Фильтр контента** — блокировка нецензурной лексики и запрещённых тем
- ⌨️ **Кнопки** — быстрый доступ к «Помощь» и «Очистить историю»
- ✍️ **Индикатор «печатает…»** во время генерации ответа
- 📨 **Длинные ответы** автоматически разбиваются на части (лимит Telegram — 4096 символов)
- 🎨 **Форматирование** — Markdown от нейросети конвертируется в безопасный HTML для Telegram (жирный, курсив, код, блоки кода)
- ⚠️ **Понятные ошибки** — отдельные сообщения при превышении лимита запросов и проблемах с ключом

## 🚀 Установка и запуск

### 1. Клонируйте репозиторий

```bash
git clone https://github.com/<ваш-логин>/<название-репозитория>.git
cd <название-репозитория>
```

### 2. Создайте виртуальное окружение (рекомендуется)

```bash
python -m venv venv
source venv/bin/activate      # Linux / macOS
venv\Scripts\activate         # Windows
```

### 3. Установите зависимости

```bash
pip install -r requirements.txt
```

### 4. Получите ключи

- **BOT_TOKEN** — создайте бота у [@BotFather](https://t.me/BotFather) в Telegram
- **GROQ_API_KEY** — получите на [console.groq.com](https://console.groq.com/keys)

### 5. Настройте `.env`

Скопируйте `.env.example` в `.env` и впишите свои ключи:

```env
BOT_TOKEN=ваш_токен_telegram_бота
GROQ_API_KEY=ваш_ключ_groq
```

### 6. Запустите бота

```bash
python bot.py
```

Если всё хорошо, в консоли появится:

```
База данных готова.
Бот Lori запущен...
```

## ⚙️ Настройки

Основные параметры находятся в `config.py`:

| Параметр          | Описание                          | По умолчанию          |
|-------------------|-----------------------------------|-----------------------|
| `GROQ_MODEL`      | Модель нейросети                  | `openai/gpt-oss-120b` |
| `TIMEZONE_OFFSET` | Смещение от UTC в часах           | `3`                   |
| `TIMEZONE_NAME`   | Название часового пояса           | `Москва`              |

Характер бота и все его тексты редактируются в `prompts.py`, списки запрещённых слов и тем — в `bad_words.py`.

## 💬 Команды

| Команда  | Описание                    |
|----------|-----------------------------|
| `/start` | Начать работу с ботом       |
| `/help`  | Справка                     |
| `/clear` | Очистить историю диалога    |

Те же действия доступны через кнопки **❓ Помощь** и **🧹 Очистить историю**.
